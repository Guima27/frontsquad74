# Squad 74 - System Atos

## Sobre o projeto
Desenvolvimento da **Plataforma de Suporte Integrada e Multicanal (Portal)** para a **Atos Capital** (Unidade de Bank), no âmbito da Residência de Software - UNIT / Porto Digital.

## Stack
- **Back-end:** C# (.NET)
- **Front-end:** React + TypeScript + MUI v5
- **Banco de dados:** PostgreSQL
- **Orquestração:** n8n (webhooks e alertas de SLA)
- **Autenticação:** SSO via JWT
